# Verslot v0.1

## Goal

Establish the core architecture and CLI contract.

This bootstrap defines command names and their positional target shape. Target
parsing and provider behavior will be added in later implementation tasks.

## Commands

verslot --version
verslot --help
verslot install <tool>@<version>
verslot uninstall <tool>@<version>
verslot use <tool>@<version>
verslot list
verslot current

## Initial provider

Node.js is the first provider planned for end-to-end support after the CLI
bootstrap. It is not implemented by the current configuration.

## Platforms

- Windows
- macOS
- Linux

- extensions
